# Парсер Яндекс.Карты + 2ГИС

Сбор данных о компаниях из Яндекс.Карт и 2ГИС в Excel.  
Поддерживает несколько городов и сфер одновременно, дедупликацию, ночной режим, прогресс-бар и graceful shutdown.

## Возможности

- **Два источника**: Яндекс.Карты + 2ГИС (чередуются, каждый получает свою долю записей)
- **Множественные города и сферы**: ввод через запятую
- **Дедупликация**: `BD/registry.json` хранит все собранные записи. Повторный запуск не соберёт дубли — ни в рамках одной сессии, ни между сессиями. Ключ — номер телефона
- **История**: `history.xlsx` — какие комбинации городов/сфер уже искались
- **Ночной режим**: увеличенные паузы (×1.3), лимит до 500 записей
- **Прогресс-бар**: `tqdm` внизу терминала
- **Ctrl+C**: graceful shutdown — браузер закрывается, registry и Excel сохраняются
- **Добивка**: если после всех комбинаций недобрали до лимита, скрипт проходит по комбинациям повторно
- **Синонимы**: если по запросу пусто, автоматически подбирает синонимы (маникюр → ногти, педикюр и т.д.)
- **Excel**: столбцы: Сфера, Город, Наименование, Телефон, Онлайн-запись, Комментарий, Ссылка на сайт, Ссылка на Яндекс/2ГИС

## Установка

### 1. Клонировать репозиторий

```bash
git clone <url>
cd database
```

### 2. Виртуальное окружение и зависимости

```bash
python3 -m venv venv
source venv/bin/activate      # bash/zsh
source venv/bin/activate.fish # fish
pip install -r requirements.txt
python3 -m playwright install chromium
```

### 3. Brave-браузер (обязательно для 2ГИС)

2ГИС блокирует headless-браузеры. Скрипт использует ваш реальный профиль Brave.  
Убедитесь, что Brave установлен и путь в скрипте (`BRAVE_PATH`, `BRAVE_PROFILE`) указан верно.

По умолчанию:
```python
BRAVE_PATH = "/opt/brave-bin/brave"
BRAVE_PROFILE = "/home/vi/.config/BraveSoftware/Brave-Browser/Default"
```

Поправьте под себя в начале `ymaps_parser.py`.

## Запуск

```bash
python3 ymaps_parser.py
```

Скрипт спросит:
1. **Ночной режим?** — да/нет (ночью паузы ×1.3, лимит до 500)
2. **Города** — через запятую (например: `Ижевск, Воткинск, Глазов`)
3. **Сфера/запрос** — через запятую (например: `бьюти, массаж`)
4. **Лимит записей** — сколько собрать всего
5. **Имя Excel-файла** — готовое имя или своё

Окно Brave откроется и уйдёт за экран (`--window-position=-3000,0`). Не закрывайте его.

## Структура файлов

```
database/
├── ymaps_parser.py      # основной скрипт
├── BD/registry.json      # реестр всех собранных записей (дедупликация)
├── history.xlsx          # история запусков
├── clients_xxxx.xlsx     # выгрузки (можно удалять, не влияет на дедупликацию)
├── archive/              # старые версии
└── venv/                 # виртуальное окружение
```

## Как работает дедупликация

1. Каждая запись идентифицируется по номеру телефона
2. Перед добавлением проверяется `BD/registry.json` — есть ли уже такой телефон
3. Если есть — запись пропускается, скрипт ищет следующую
4. Все записи хранятся в `registry.json` с полными данными (телефон, адрес, сайт и т.д.)
5. `.xlsx`-файлы — это снапшоты, их можно удалять без потери данных

## Примечания

- 2ГИС работает **только** через реальный профиль Brave. Без него — капча или пустые результаты.
- Яндекс.Карты работают в headless-режиме.
- `BD/registry.json` и `history.xlsx` создаются автоматически при первом запуске.
